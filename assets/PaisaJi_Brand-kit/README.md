# PaisaJi (Paisaजी) Official Branding Package

This package contains the official, approved PaisaJi branding assets **with all taglines permanently removed**.

## Identity Standards
- **Official Brand Name**: PaisaJi
- **Official Wordmark**: Paisaजी (English "Paisa" + Devanagari "जी")
- **Logo Symbol**: P + ₹ Monogram
- **Primary Navy**: `#0A2342`
- **Primary Blue**: `#007BFF`
- **Tagline**: None (Retired)

## Included Assets
- Primary Horizontal Logo (`paisaji_primary.png`, `paisaji_primary_white.png`, `paisaji_white_darkbg.png`)
- Horizontal Wordmark (`paisaji_wordmark.png`)
- Stacked Logo (`paisaji_stacked.png`, `paisaji_stacked_white.png`)
- Monogram Symbol (`paisaji_monogram.png`, `paisaji_monogram_white.png`)
- Transparent PNG Variants
- Monochrome Black and White Versions
- Android Adaptive and Launcher Icons (`android/`, `launcher/`)
- Web Favicons & App Icons (`web/`)
- Responsive Resolution Assets (`responsive/` @1x, @2x, @3x)

## Recommended Flutter Usage
```dart
Image.asset(
  'assets/branding/paisaji_primary.png',
  fit: BoxFit.contain,
)
```

## Recommended Web Usage
```tsx
<img
  src="/branding/paisaji_wordmark.png"
  alt="Paisaजी"
  className="h-9 w-auto object-contain"
/>
```
